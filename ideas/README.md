# Идеи

Каталог для быстрого capture новых идей.

Правила:
- идея должна создаваться быстро, без обязательной декомпозиции;
- идеи не передаются напрямую в Codex;
- идеи сначала проходят triage через DeerFlow или ручной разбор;
- после triage идея либо архивируется, либо превращается в research/task/dispatch цепочку.
