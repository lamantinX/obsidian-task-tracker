# Dispatch

Каталог для явных handoff-пакетов.

Назначение:
- передача задач в DeerFlow для triage, research, planning, routing;
- передача подготовленных execution-задач в Codex;
- фиксация явного dispatch, чтобы исключить несанкционированный autonomous loop.

Правило:
- без dispatch note задача не считается готовой к исполнению Codex.
