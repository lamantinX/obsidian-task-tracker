Создать или обновить сегодняшнюю daily note для team mode.

## Логика
1. Проверь daily note в `daily/{YYYY}/{MM}/{YYYY-MM-DD}.md`.
2. Покажи:
   - due today;
   - overdue;
   - in progress;
   - ready for DeerFlow;
   - ready for Codex;
   - waiting review.
3. Добавь короткий блок knowledge activity:
   - новые research notes;
   - новые permanent/literature notes;
   - knowledge inbox items.
4. Git activity собирай из `repo` в project files.
