# База знаний

Этот каталог — общая командная база знаний в стиле Zettelkasten.

Структура:
- `inbox/` — входящие знания и черновые заметки;
- `notes/` — постоянные и source/literature notes;
- `structures/` — обзорные MOC/structure notes;
- `projects/` — project-level knowledge boards;
- `repos/` — repo-level knowledge boards.

Принципы:
- знания хранятся в markdown и связываются ссылками;
- DeerFlow может synthesise, link и route знания;
- Codex не исполняет задачи напрямую из knowledge inbox.
