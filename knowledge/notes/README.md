# Постоянные и source notes

Используйте этот каталог для:
- `permanent` notes — устойчивые выводы и наблюдения;
- `literature` notes — конспекты источников;
- `meeting` notes — выжимки командных обсуждений.

Каждая заметка должна по возможности ссылаться хотя бы на одну структуру, задачу, research note или соседнюю заметку.
