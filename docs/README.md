# Документация vault

В этом каталоге хранится русскоязычная документация по командной эксплуатации vault.

Основные документы:
- `team-architecture-audit.md` — краткий аудит текущей структуры.
- `task-schema.md` — каноническая схема задач и handoff-полей.
- `deerflow-orchestration-workflow.md` — правила orchestration через DeerFlow.
- `codex-execution-workflow.md` — правила передачи задач в Codex.
- `server-deployment.md` — рекомендуемая серверная схема.
- `migration-notes.md` — список изменений и ручных шагов после обновления.
